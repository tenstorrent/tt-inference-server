This page must be served from (or CORS-allowed by) the same origin as the TTS server, since the request needs a custom Authorization header. Opening this file directly (file://) against a remote host will fail with a network/CORS error in the browser console. "Chunks received" counts distinct reads of audio bytes off the HTTP stream on the client side — the closest thing observable from the browser to the server's internal audio chunks. Audio is played in real time via the Web Audio API as chunks arrive (with a small lead buffer to absorb network jitter); the player below holds the fully assembled clip for replay/seeking.
